# 商店上架文案（Edge 加载项）

## 名称
平行工作台（Parallel Workbench）

## 简短说明（≤132 字符）
多模型平行问答：一次提问，ChatGPT、DeepSeek、豆包、Kimi、通义千问、文心一言并排回答。

## 详细说明

**为什么需要它？**
比较不同 AI 模型的回答，通常要在多个标签页之间反复切换、复制粘贴。平行工作台把多个 AI 平台的官方网页客户端并排嵌入一个工作台：顶部一个输入框，一键同步提问，各模型的回答平行展示，一眼对比，避免信息茧房。

**特性**
- 统一输入框，一键同步发送到所有勾选的模型（支持多行输入）
- 各平台官方界面嵌入显示；部分附件或认证能力受平台 iframe 策略限制时会明确提示
- 使用同一 Edge 浏览器配置；登录态能否直接复用取决于平台 Cookie/存储策略，也可在工作台登录流程中完成认证
- 每个窗格独立状态角标（就绪/未登录/需验证）+ 发送结果反馈
- 不调 API、无付费依赖

**隐私**
本扩展不运营自己的中转服务器，也不收集分析数据。用户输入的问题和选择的附件会直接发送给其勾选的第三方 AI 平台，并受相应平台的隐私政策约束；登录态保存在 Edge 浏览器配置中。扩展权限用于嵌入平台页面、向指定平台 frame 注入用户发起的内容、状态探测，以及尽力而为的附件拖放。

**支持平台**：ChatGPT、DeepSeek、豆包、Kimi、通义千问、文心一言（国际平台需你自己的网络代理环境，扩展不提供任何代理能力）。
